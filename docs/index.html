INSTALLATION & USAGE

Package Manager:

Run directly in any directory without installing or altering package.json:

npx github:PRN-6/web66

Install globally to have the web66 binary permanently in your terminal PATH:

npm install -g github:PRN-6/web66

Then just run web66 in any project folder!

Run with pnpm's instant binary executor:

pnpm dlx github:PRN-6/web66

Ultra-fast execution with Bun:

FREQUENTLY ASKED QUESTIONS

Does Web66 upload my code to the cloud?

Never. Web66 is 100% offline and runs completely on your local machine. It starts a localhost HTTP and WebSocket server. Zero bytes of code or metadata leave your computer.

How do other developers run it without installing?

Anyone with Node.js installed can simply run npx github:PRN-6/web66 in any project directory. It fetches the lightweight 21 KB bundle and launches immediately.

Why did nodes jitter/dance in other visualizers?

Standard force-directed graph algorithms suffer from infinite repulsion oscillations. Web66 implements simulation temperature decay (simAlpha cooling) and dynamic orbit tier scaling, locking nodes steadily in place once settled.

Can Web66 handle large monorepos?

Yes! Web66 features built-in ignore filters for node_modules, .git, build artifacts (dist, .next), and parses hundreds of modules in under 50ms.
