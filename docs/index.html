>_ // about web66

Google Maps for Source Code. Transforms any codebase into an explorable cosmic web of organic glowing blobs.

Web66 is a universal codebase intelligence engine. It scans your Abstract Syntax Tree (AST), extracts functions, classes, and dependencies, and renders an interactive radial galaxy on your localhost with instant live sync.
