# Security Policy

## Reporting a Vulnerability

We take the security of Web66 seriously. If you find a security vulnerability, please do not open a public issue. Instead, please report it privately via email to: security@example.com.

## Our Process
1. We will acknowledge receipt of the report within 48 hours.
2. We will work on a fix and keep you updated on the progress.
3. Once the fix is released, we will credit you for the discovery if you wish.
